### Systems and C++

- [limitorderbook](https://github.com/allenwang0/limitorderbook) ([report](https://allenwang0.github.io/limitorderbook/)): an order matching engine with price-time priority and constant-time cancels.
- [hashbench](https://github.com/allenwang0/hashbench): three hash maps built from scratch in C++20, fuzzed and benchmarked against `std::unordered_map`.

### Quant finance

- [quantsim](https://github.com/allenwang0/quantsim) ([report](https://allenwang0.github.io/quantsim/)): a Python backtesting framework with walk-forward testing and paper trading.
- [statarb](https://github.com/allenwang0/statarb): pairs trading with a Kalman-filter hedge ratio and out-of-sample tests.
- [volatilityscanner](https://github.com/allenwang0/volatilityscanner) ([report](https://allenwang0.github.io/volatilityscanner/)): a live implied-volatility surface with smile fits and arbitrage checks.
- [kalshibot](https://github.com/allenwang0/kalshibot) ([report](https://allenwang0.github.io/kalshibot/)): prices Kalshi Fed-rate markets from fed funds futures.
